## Featured work

### Park Tennis Brand Index

I started Park Tennis to help public-court players discover independent tennis brands. I chose to build a guide before building a store, created a rubric for selecting brands, and put a research and editorial review workflow behind the live index.

[Case study](https://joshuasigler.com/work/park-tennis-brand-index/) · [Live Brand Index](https://parktennis.com/brands)

### Resale Workflow

I built a photo-first workflow for preparing and reviewing listings, then used it to sell and ship clothing on Depop and Vinted. The public Node.js demo uses fictional examples to show how an intake folder becomes a draft with a price suggestion and a review checklist.

[Case study](https://joshuasigler.com/work/resale-workflow/) · [Run the demo](https://github.com/joshuasigler/resale-workflow-demo)
